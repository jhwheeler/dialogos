# Dialogos Product Overview (v0.1 draft)

## Product definition
Dialogos is an audio-first practice environment for oral understanding.

A student speaks from memory and is guided by short Socratic prompts that enforce:
- clarity
- definitions/distinctions
- argument structure
- rhetorical precision

## Product stance
Dialogos is not a summarizer, note-writer, or debate toy.

It is a formation tool where the student does the intellectual labor while the system acts as:
- coach
- examiner
- sparring partner
- structure enforcer

## Core loop (10–15 min)
1. Choose source/topic
2. Brief arrival prompt
3. Voice recall from memory
4. Trivium moves (grammar, logic, rhetoric)
5. Socratic follow-up (one move at a time)
6. Compression (one-sentence restatement)
7. Closure (what remains unclear)
8. Optional export (transcript/summary/rubric)

## Non-negotiable behavior rules
- No sycophancy
- No auto-synthesis on behalf of the student
- One concise prompt per assistant turn
- Audio-first and low-screen interaction

## MVP focus
Must-have: voice session loop, source attachment support, Socratic prompting, transcript/summary/rubric artifacts.

Deferred: spaced repetition, social features, and advanced embodied modules.
