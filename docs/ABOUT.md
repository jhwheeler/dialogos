# About Dialogos

Dialogos is a voice-first training app for oral mastery.

The app is designed to help a student think and speak clearly under constraints, using:
- trivium progression (grammar → logic → rhetoric)
- Socratic questioning
- short, repeatable, audio-first practice sessions

Core principle: the app supports intellectual formation without doing the synthesis for the student.
