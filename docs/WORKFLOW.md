# Development Workflow

## How we work
- Keep pull requests focused and small.
- Prefer service-layer logic over route-layer logic.
- Add or update tests for behavior changes.
- Keep docs in sync with implementation.

## Product behavior constraints (MVP)
- Socrates Mode is always on.
- One move per turn (single concise prompt).
- No sycophancy, no filler, no unsolicited recap.
- Audio-first UX and source-grounded sessions.

## AI collaboration
- Start with `AGENTS.md` and docs in `docs/`.
- Use repo skills in `skills/` for repeatable patterns.
- Preserve anti-offloading constraints: AI challenges form, student provides substance.
